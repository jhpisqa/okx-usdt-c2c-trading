## 付款前核对四项，付款后记得回来点一次

转账之前，把页面上的四样东西对一遍：**实际支付金额、预计获得多少 USDT、商家收款资料、付款倒计时和订单提示**。页面如果提示资产使用限制，先看懂条件再决定要不要继续。

用与身份认证同名的本人账户付款。商家要求在订单之外换一个收款人，或者让你去微信、Telegram 私聊成交，停下来。商家常在订单备注里写「转账不要备注任何信息」「禁止延迟到账」，这些按订单页面和聊天窗口的提示操作就行，不是平台统一规则，但照做能少一层麻烦。支付应用如果弹出「对方账户存在风险」并直接拦截转账，取消这一单，换一家。

付完款回到订单页点【我已支付】，平台要求就上传凭证。钱没转出去不要提前点，钱转出去了别忘点。已付款的订单不要自己取消，也不要重复转第二笔。订单意外取消不代表你的转账会自动退回。

## 「0 手续费」不等于同价，1000 元能差出 2 USDT

自选区按钮上写的是「0 手续费购买」，指的是平台通常不收撮合手续费。你真正付出的成本分三层：平台撮合费（C2C 通常为 0）、商家报价（决定同样金额能换多少 U）、付款渠道费用（银行或支付服务商可能另收）。

计算方式很简单：**预计到账 USDT = 付款金额 ÷ 每 USDT 报价**。

下面这组报价只是用来演示算法，不代表任何时点的真实行情：

| 商家报价 | 支付 1000 元预计获得 |
| --- | --- |
| 7.10 CNY/USDT | 140.85 USDT |
| 7.15 CNY/USDT | 139.86 USDT |
| 7.20 CNY/USDT | 138.89 USDT |

同样 1000 元，两端相差约 **1.96 USDT**。这就是为什么「0 手续费」不能理解成「完全免费」，也不能理解成「所有商家一个价」。当天的实际报价只看订单页。

## 商家怎么筛：看五个字段，再划掉六类

自选区列表上能直接看到的字段就这么几个，按顺序看：

1. **完成率**：98% 以上，能到 99% 更稳。
2. **成交单量**：1000 单以上算有历史，2000 单以上更放心。
3. **注册时长**：成为商家半年以上，点商家头像能看到时间。
4. **单笔限额**：你的金额必须落在最低和最高之间，别为了凑限额超出自己能承担的范围。
5. **付款方式**：是不是你本人能合法使用的那种。

这几项要合起来看，完成率高、单量大只是参考，不代表这笔交易没有风险。

遇到下面任何一种，直接换商家，别为了便宜几分钱去试：

- 要求向订单以外的收款人付款
- 要求用别人的付款账户
- 要求转去 Telegram、WhatsApp 或微信私聊成交
- 要求先付保证金或手续费
- 订单金额和收款资料对不上
- 附加条件你看不懂或者做不到

大额需求可以优先挑标注了钻石商家、单量和完成率都高的委托单，但仍然建议拆成几笔、分时段下单。

## 付了钱商家不放币，按这个顺序处理

先自查三件事：付款记录是否显示成功、订单是否已经确认付款、收款人和金额是否与订单一致。都对得上，就在订单内联系商家。商家还是不放币，走申诉：App →【C2C 买币】→【订单】→ 选对应订单 →【需要帮助？】→ 先联系商家 → 无法解决再选问题类型 →【发起申诉】→ 提交证据。

| 你遇到的情况 | 怎么处理 |
| --- | --- |
| 还没付款，订单快超时 | 别急着转，按订单规则取消或重新选 |
| 已付款，商家不放币 | 存好付款记录，订单内联系，必要时申诉 |
| 已付款，忘了点【我已支付】 | 回订单页按官方入口补确认并上传凭证 |
| 金额付错 | 保留原始凭证，向商家说明，按平台争议流程走 |
| 已付款但订单被取消 | 联系客服，提供订单号和付款记录 |

要留的证据有五类：C2C 订单号、付款时间与实际金额、银行或支付应用的交易凭证、订单内聊天记录、平台要求的其他材料。所有沟通和赔付都走平台内渠道，站外提出的「解冻费」「保证金」一律不接。

## T+N：买完提不了币，最可能是这个原因

T+N 是欧易针对部分 C2C 买入订单设置的安全保护。平台会按交易风险评估，对**该笔订单等额的数字资产**设置临时使用限制。

官方列出的档位是 T+3（3 个自然日）、T+7（7 个自然日）、T+15（15 个自然日），部分订单也可能显示 T+1 等更短或不同的期限，具体天数看订单页面。

受限的动作有三个：提币、C2C 卖出、DEX 交易。

限制一般只针对这一笔订单等额资产，不代表整个账户所有资产都动不了；解除时间以订单页显示为准。符合条件的用户可以通过官方申诉入口提交材料，但不保证能提前解除。

银行卡被冻结和 T+N 是两套完全不同的机制。卡的问题由银行、支付机构或有关机关处理，原因和处理方式都不一样，别把两件事混在一起想。如果付款账户被限制，按银行和支付机构的要求如实说明情况、配合核查，不要靠换账户或拆单绕过去。

C2C 买入的数字资产通常进入**资金账户**。部分版本需要在资金账户和交易账户之间划转一次才能去现货交易，App 路径是【资产】→【资金划转】→ 填数量 →【确认】，以你实际看到的页面为准。

## 常见问题

**人民币能直接充值进欧易吗？**
不能。人民币入金走 C2C，向商家买 USDT。页面是否提供 CNY 和可用商家，由账户所属地区、身份认证状态和平台规则决定，不保证任何地区都能用人民币 C2C。

**支付宝、微信、银行卡都能用吗？**
看订单是否提供该选项，以及你的账户是否符合使用规则。没有任何一种付款方式能保证不触发风控，用本人实名账户、不接第三方代付，能减少一部分争议。

**多久能到账？**
没有统一时间。付完款点了【我已支付】，等商家确认收款后平台放币，具体以订单页面为准。超过预期还没动静，就在订单内联系商家。

**为什么买完不能提币？**
先看订单详情有没有 T+3、T+7、T+15 之类的提示，有就是触发了 T+N；没有的话再查提现权限、网络支持和账户状态。

**付了钱商家不放币，钱会没吗？**
下单后商家的 USDT 已经被平台锁定，凭付款凭证走订单内沟通和申诉流程处理。不要取消已付款订单，也不要再转一笔。

**订单取消了，转出去的钱会自动退回吗？**
不会。订单状态取消和转账是否退回是两件事，保存原始订单和付款记录，联系平台核查。
